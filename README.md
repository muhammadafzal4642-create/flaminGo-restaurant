# 🦩 FlaminGo Restaurant - Authentic Filipino Cuisine

A modern, responsive web application for **FlaminGo Restaurant**, featuring an interactive menu, online ordering system, WhatsApp integration, and authentic Filipino food showcase.

Built with **React 19, TypeScript, Vite, Tailwind CSS v4, Lucide Icons, and Motion**.

---

## 🚀 Quick Start (Development)

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the local dev server:**
   ```bash
   npm run dev
   ```

3. Open your browser at `http://localhost:3000`.

---

## 🛠️ Build for Production

```bash
npm run build
npm run preview
```

The output bundle will be generated in `dist/`.

---

## 🌐 Deploy to Vercel

This repository is pre-configured with `vercel.json` for seamless Vercel deployment:

1. Import this repository `muhammadafzal4642-create/flaminGo-restaurant` on [Vercel](https://vercel.com/new).
2. Framework Preset: **Vite**
3. Build Command: `npm run build`
4. Output Directory: `dist`
5. Click **Deploy**.
